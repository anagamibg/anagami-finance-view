# Скрийншоти — Сесия 2 (въвеждане на финансови данни и импорт)

Сървър: `php artisan serve --port=8123` → `http://127.0.0.1:8123`. Вход: `admin@demofinans.bg` с паролата по подразбиране на `databackd:demo` (`DatabackdDemoSeeder::PASSWORD`) (демо компания „Демо Финанс Груп“, виж `docs/mvp/DEMO.md`). Менюто е в раздел **„Финансов анализ“**.
Преди снимките: `php artisan databackd:demo --only=DataDemoSeeder` (идемпотентно).

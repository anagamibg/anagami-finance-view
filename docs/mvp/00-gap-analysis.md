# Anagami Finance View MVP — функционалности по проекта и gap анализ

Източник: „Информация за програмата ИСУН 2020 — Anagami Finance View“ (BG16RFPR001-1.001, „Аутсорса“ ЕООД, 18 месеца, цел TRL 7 — прототип, демонстриран в операционна среда).
Състояние на кода: AFV (Ð±Ð°Ð·Ð°: Froiden) 6.0.10 (Laravel 12, SaaS режим) — PM/HR/CRM/фактуриране. Специфичните за проекта финансово-аналитични функции **липсват**; има само базови финансови модули (фактури, плащания, разходи, банкови сметки) и няколко отчета.

## 1. Функционалности, описани в документа

### А. Изрично изброени функционалности на иновацията (т. 3 / т. 4 от формуляра)
| # | Функционалност | Какво точно се очаква |
|---|---|---|
| F1 | **Финансови справки и репорти** | „Пластични“ — ежедневни, месечни, годишни; клиентът избира какви данни и по какви разрези |
| F2 | **Финансови коефициенти** | „Пластични, според нуждите“ — стандартни + дефинирани от клиента формули |
| F3 | **Всеобхватно въвеждане на счетоводни и финансови данни** | Ръчно въвеждане според нуждите на клиента |
| F4 | **Импорт от Excel и Google Sheets** | |
| F5 | **Импорт от други платформи и източници** | „С развитието на платформата“ — може да е заявено/частично в MVP |
| F6 | **Финансово планиране, бюджетиране и прогнози** | Бюджет, бюджет vs. реално, прогноза |
| F7 | **Консолидация** | Фирми с подразделения / няколко пазара; клиентът „задава принципа, на който данните се обединяват“ |
| F8 | **Визуализация на данни** | Графики, табла |

### Б. Изисквания, описани в текста около функционалностите
| # | Изискване | Откъде |
|---|---|---|
| R1 | Разрези на данните: оборот по видове продукти и услуги, **географско обособяване**, **видове клиенти**, периоди, видове приходи и разходи по определен принцип | т. 1 (описание на иновацията) |
| R2 | Данни за контрагенти, договори, цени, себестойност, заплати | т. 1 |
| R3 | Различни видове обработка — съхранение, справки, формули, коефициенти, обединяване на данни | т. 1 |
| R4 | **Услуга + екип**: клиентът поръчва специалисти (екипи от 1, 2, 5, 10, 20, 50+ души) или само няколко часа седмично; месечно поставяне на задачи за анализи, справки, репорти | т. 1, т. 3 „Как работи продуктът заедно с услугата“ |
| R5 | FP&A, консолидация, съответствие и отчетност (compliance/reporting) | т. 21 |
| R6 | SaaS, уеб достъпно от различни устройства | т. 1.2 |
| R7 | Сигурност и защита на данните | т. 21 (уникални характеристики, т. 5) |
| R8 | Анализ и отчетност в реално време | т. 21 (т. 7) |
| R9 | Подходящ за микро/малки фирми — лесна употреба, бързо внедряване | т. 3 показател 1 |
| R10 | Тестване на функционалност и сигурност; техническа документация | Етапи 3 и 4 |

## 2. Какво има и какво няма в кода

| # | Функционалност | Статус | Какво има в кода | Какво липсва | Сесия |
|---|---|---|---|---|---|
| F1 | Финансови справки и репорти | 🟡 Частично | `FinanceReportController` (плащания), `IncomeVsExpenseReportController`, `ExpenseReportController`, `SalesReportController` | Групиране ден/месец/година, ОПР (P&L), паричен поток, разрези (регион, вид клиент, продуктова група), запазени справки, експорт | S3 |
| F2 | Финансови коефициенти | 🔴 Няма | — | Сметкоплан + балансови данни, стандартни коефициенти, потребителски формули | S4 |
| F3 | Въвеждане на счетоводни/финансови данни | 🟡 Частично | Фактури, плащания, кредитни известия, разходи, банкови сметки | Сметкоплан, универсални финансови записи (приходи/разходи/салда), измерения R1 | S1 (модел) + S2 (UI) |
| F4 | Импорт от Excel / Google Sheets | 🟡 Частично | Инфраструктура за импорт (`maatwebsite/excel`, batch jobs, `ImportController`) за клиенти, разходи, продукти, служители; `google/apiclient` е инсталиран | Импорт на финансови записи с mapping на колони; Google Sheets изобщо няма | S2 |
| F5 | Импорт от други платформи | 🔴 Няма | REST API (`ApiRoute`) за стандартните модули | Страница „Интеграции/източници“, generic CSV/JSON импорт, API endpoint за финансови записи | S2 |
| F6 | Планиране, бюджетиране, прогнози | 🔴 Няма | — | Бюджети, бюджет vs. реално, прогнози/сценарии | S5 |
| F7 | Консолидация | 🔴 Няма | SaaS мулти-компания (но изолирани tenant-и) | Група от юридически лица, правила за консолидация, консолидирани отчети | S1 (модел) + S4 |
| F8 | Визуализация на данни | 🟡 Частично | Frappe/Chart.js компоненти (`x-line-chart`, `x-bar-chart`, `x-pie-chart`…), разширено табло с таб „Финанси“ | Финансово табло с KPI, тенденции, разрези | S3 |
| R1 | Разрези (регион, вид клиент, продукт…) | 🔴 Няма | — | Измерения във финансовите записи | S1 |
| R2 | Контрагенти, договори, цени, себестойност, заплати | 🟡 Частично | Клиенти, договори, продукти (цена), служители | Себестойност; модул Payroll **не е инсталиран локално** (`Modules/` има само LanguagePack) → заплати като разходна сметка | S1 |
| R4 | Поръчка на екип специалисти + месечни задачи | 🟡 Частично | Служители, проекти, задачи, отчитане на време | Заявка за екип (1/2/5/10/20/50, часове), заявки за анализ към екипа | S5 |
| R6 | SaaS, уеб, мобилни устройства | 🟢 Има | AFV SaaS, responsive Bootstrap 4 | — | — |
| R7 | Сигурност | 🟢 Има (базово) | Fortify, 2FA, роли/права (Entrust), XSS middleware | — | — |
| R8 | Реално време | 🟡 Частично | Табла се смятат директно от БД | — | S3 |
| — | Примерни данни | 🔴 Няма | Демо seeders съществуват, но **не се пускат при `APP_ENV=codecanyon`** | Демо компания с 18 месеца данни | S1 + всяка сесия |

## 3. Модули, които се скриват от фронтенда (не се трият)

Скриват се **само менюта, табове, бутони и екрани**; routes и код остават. Управлява се от `config/databackd.php` → `hidden` (S1).

| Остава видимо (нужно по проекта) | Скрива се |
|---|---|
| Табло (лично + разширено: само „Общ преглед“ и „Финанси“) | Табове на таблото: Проекти, Клиенти, HR, Тикети |
| Клиенти (= контрагенти) | Лийдове, Сделки |
| HR → Служители (= екипът специалисти), Отдели, Длъжности | Отпуски, Смени, Присъствие, Празници, Признания/награди |
| Работа → Договори, Проекти, Задачи, Отчитане на време | — |
| Финанси → Фактури, Плащания, Кредитни известия, Разходи, Банкови сметки | Оферти (Proposals), Проформи (Estimates), Абонаменти |
| Продукти | Поръчки (Orders) |
| Отчети → Финансов, Приходи vs. разходи, Разходи, Продажби, Отчитане на време | Отчети: Задачи, Седмичен timesheet, Отпуски, Присъствие, Сделки |
| Настройки (общи, фактури, валути, данъци, роли, сигурност) | Тикети, Събития, Съобщения, GDPR, Табло за обяви, База знания, Бележки, Моят календар; настройки на скритите модули |
| **Нов раздел „Финансов анализ“** (S2–S5) | |

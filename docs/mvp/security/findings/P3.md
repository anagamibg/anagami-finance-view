# S6 / P3 — Инжекции: SQL, XSS, FormulaEngine, RCE/други инжекции

Дата: 2026-10-28. Обект: целият код на фаза 1 (`app/**/Databackd/**`, `routes/databackd/**`, `resources/views/databackd/**`, `resources/views/notifications/**`, `app/Exports/**`, mail/notification класове) + новият модул `Gaps` (прегледан само за инжекционни класове).

Метод: (1) `grep` на всички `DB::raw`/`selectRaw`/`whereRaw`/`orderByRaw`/`groupByRaw`/`havingRaw`, динамични колони и `{!! !!}`/inline JS/`.html()`/`innerHTML`/`rawColumns`/`HtmlString`/`e()`; (2) четене на всеки намерен израз докъде стига потребителски вход; (3) **черна кутия през HTTP kernel без сървър** (скриптове по модела на `docs/mvp/tools/smoke.php` + `DB::listen`, за да се види дали враждебен текст стига до **SQL текста**, а не само до bindings); (4) доказателства за XSS на ниво изходен HTML/JSON (временни редове `S6-TMP-P3…`, в транзакция с rollback, COUNT = 0 след всеки тест); (5) хостилни входове за FormulaEngine (преди и след поправките); (6) изолиран PoC на dompdf `eval`.

## 2. Известни пропуски, потвърдени от handoff-ите (взети в B7)
- `02-data.md`: „Списъкът ‘Финансови записи’ няма колона ‘център на разходи’“ → B7.
- `03-reports.md`: ОПР линкът към списъка носи само `account_id`; `databackd:send-reports` не е в scheduler → B7, B8.
- `05-planning-teams.md`: breadcrumb „Analysis“; няма автосейв на клетките в редактора на бюджет; `recurring-analysis` не е в scheduler → B7, B8.

## 3. Какво остава извън S8 (съзнателно)
Google OAuth за непублични листове; директни API интеграции с конкретни платформи (не само файлов импорт) и банкови API (PSD2); Payroll интеграция; одитна следа (журнал на промените) за финансовите записи; автоматизирани PHPUnit тестове; официален формат за подаване на ГФО (XML към НСИ/Търговски регистър).
